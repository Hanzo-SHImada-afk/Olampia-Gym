## 🏋️ About The Project

Olympia Gym is a **self-designed fictional gym website** created as a personal training project.

The main goal of this project was to practice building a complete website using **HTML and CSS**, while experimenting with layouts, typography, colors, navigation, cards, buttons, and responsive design.

## 🎨 Design

The design was created from scratch with a strong **black + gold fitness aesthetic**.
